#create branch QA
The function of this microservice is to search for and identify the role each user has, i.e., 
whether they are a client or an organizer. In this case, the ID and profile type are used. 
If the profile exists, it loads that user's data.

## Overview
A Spring Boot microservice designed for user role and permission management in distributed system architectures. 
This service provides a robust API for creating, managing, and assigning roles to users with comprehensive validation and error handling.
